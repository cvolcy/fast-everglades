About this project

Overview

A minesweeper clone built using Vue.js and HTML5 Canvas. Configure grid size and mine count, then click cells to reveal them. Avoid the mines — or face the consequences!

Vue.js Canvas API JavaScript HTML5

How it's built

Architecture

A simplified representation of the architecture used for the game.

C

Cell

Represents a single square on the grid. Responsible for its own rendering via the Canvas 2D API.

  • x, y, w — position & size in canvas pixels
  • hasAMine — whether the cell contains a mine
  • revealed — has the player uncovered it
  • flagged — player-placed flag marker
  • neighborsCount — adjacent mine count (cached)
show(darkMode) reveal(grid) minesCount(grid) contains(x,y)
G

Grid

A 2D array Cell[cols][rows] managed by the Vue instance. Mines are seeded randomly then each cell pre-computes its neighbor count.

  • cols × rows — configurable 5–50 each axis
  • mines — up to 90 % of total cells
  • Flood-fill reveal for zero-neighbor cells (recursive)
  • Win detected when all safe cells are revealed
V

Vue 3 App

Acts as the controller. Owns reactive state and wires DOM events to game logic.

  • state — PENDING / STARTED / WIN / OVER
  • flagCount / flagsRemaining — computed
  • darkMode — persisted via localStorage
  • Triggers canvas redraw on every state change
</>

Canvas Renderer

HTML5 <canvas> is the sole rendering surface. Each frame clears and redraws all cells imperatively.

  • Cell size auto-scales to canvas width ÷ cols
  • Radial gradient glow for revealed mines
  • Color-coded neighbor numbers (1–8)
  • Gold pennant flag drawn via Canvas path API

Data Flow

User Click / Right-Click Vue Event Handler Cell.reveal / .flagged draw() → Canvas 2D State Update (WIN / OVER)

How to play

Controls

🖱️

Left Click

Reveals the cell. If the cell has no neighboring mines, a flood-fill automatically uncovers all connected safe cells. Clicking a mine ends the game immediately.

🚩

Right Click

Toggles a flag on an unrevealed cell. A flagged cell cannot be accidentally revealed by a left-click. Right-click again to remove the flag.

Reading the Numbers

When a safe cell is revealed, it shows how many of its 8 surrounding neighbors contain a mine. Use these numbers to deduce where mines are hiding.

1 1 mine
2 2 mines
3 3 mines
4+ danger!
0 — safe zone

Goal

Reveal every safe cell on the board without detonating a mine. You win the moment all non-mine cells are uncovered — flagging every mine is not required, but it helps you track them.

Reveal all safe cells
Flag suspected mines
Avoid all mines
